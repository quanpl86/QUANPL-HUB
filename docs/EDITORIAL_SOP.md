# EDITORIAL_SOP

## Mục tiêu
Biến mỗi bài viết thành một tài sản nội dung có khả năng:
1. trả lời nhu cầu thật;
2. có bằng chứng;
3. tạo original value;
4. được Search/AI Search hiểu;
5. kết nối vào topic cluster;
6. được cập nhật theo thời gian.

## Quy trình chuẩn

### Phase 0 — Intake
- Xác định yêu cầu.
- Kiểm tra bài đã tồn tại chưa.
- Xác định Pillar / Cluster / Supporting / Update / Tool-Asset.
- Xác định priority.

### Phase 1 — Research
- Nguồn chính thức.
- Nghiên cứu gốc.
- Báo cáo quốc tế.
- Tài liệu kỹ thuật chính chủ.
- Nguồn Việt Nam để đảm bảo bối cảnh địa phương.
- Ghi rõ claim nào là fact, analysis, scenario.

### Phase 2 — Content Architecture
Tạo:
- title;
- search intent;
- primary keyword;
- reader problem;
- thesis;
- outline;
- key takeaways;
- original asset;
- internal links;
- references.

### Phase 3 — Draft
Nguyên tắc:
- answer-first;
- đoạn ngắn;
- heading rõ;
- có ví dụ;
- hạn chế jargon;
- dịch thuật ngữ sang tiếng Việt khi có thể;
- giữ thuật ngữ quốc tế trong ngoặc khi thực sự cần.

### Phase 4 — Original Value
Tối thiểu 1 asset:
- framework;
- checklist;
- rubric;
- template;
- worksheet;
- self-assessment;
- SOP;
- interactive demo;
- calculator;
- benchmark;
- dataset nhỏ;
- mini research.

### Phase 5 — Visual
- Cover 16:9.
- 3 ảnh nội dung khi bài dài/chuyên sâu.
- Mỗi ảnh gắn đúng section.
- Alt text mô tả ý nghĩa, không nhồi keyword.

### Phase 6 — SEO/AIO QC
Kiểm:
- title;
- description;
- slug;
- H1;
- canonical;
- schema;
- author;
- datePublished/dateModified;
- internal links;
- citation;
- entity consistency;
- TL;DR;
- FAQ nếu cần.

### Phase 7 — CMS
- Upload ảnh.
- Gắn ảnh đúng vị trí.
- Kiểm layout.
- Kiểm link.
- Kiểm metadata.
- Preview mobile/desktop.
- Publish/Review.

### Phase 8 — Index
Sau publish:
- sitemap có URL chưa?
- canonical đúng chưa?
- HTTP 200?
- robots/noindex?
- GSC URL Inspection.
- Bing URL Inspection.
- submit IndexNow khi phù hợp.
- xác nhận crawler có thấy rendered content.

### Phase 9 — Distribution
- Internal link từ pillar.
- Internal link từ 2–5 bài liên quan.
- Chia sẻ ở kênh chuyên môn phù hợp.
- Tạo tài sản downloadable/tool để tăng backlink.

### Phase 10 — Measure
Theo dõi:
- indexed;
- impressions;
- query;
- position;
- CTR;
- backlinks;
- AI referrals;
- AI citations;
- engagement.

### Phase 11 — Update
Trigger update:
- chính sách đổi;
- công nghệ đổi;
- data cũ;
- impressions cao nhưng CTR thấp;
- ranking 8–20;
- bài mất traffic;
- nguồn mới quan trọng;
- cluster thiếu internal link.

## Definition of Done
Một bài chỉ được coi là hoàn thành khi:
- nội dung đạt QC;
- ảnh đạt;
- metadata đạt;
- URL public;
- indexability không có lỗi rõ;
- internal links đã gắn;
- tracker được cập nhật.
