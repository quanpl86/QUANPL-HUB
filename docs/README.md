# KINGDRAGONHUB PROJECT V1

Bộ này dùng để tạo một Project/Work riêng cho KingDragonHub.

## Cấu trúc
1. `KINGDRAGONHUB_PROJECT_INSTRUCTION_V1.md` — dán vào Project Instructions.
2. `KINGDRAGONHUB_MASTER_CONTEXT.md`
3. `EDITORIAL_SOP.md`
4. `SEO_AIO_PLAYBOOK.md`
5. `ISSUES_AND_SOLUTIONS.md`
6. `DECISION_LOG.md`
7. `ROADMAP.md`
8. `CONTENT_INVENTORY.md`
9. `SEO_INDEX_TRACKER.md`
10. `EXPERIMENT_LOG.md`
11. `NEXT_ACTIONS.md`

## Cách dùng
- Dán file Instruction vào phần hướng dẫn của Project.
- Upload các file còn lại vào Project Knowledge.
- Khi bắt đầu phiên mới, yêu cầu AI đọc Master Context + Next Actions + Decision Log.
- Sau task quan trọng, cập nhật các file liên quan.
